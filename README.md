# Final project

Emotion Detector: a Flask application that analyzes customer feedback using the
embeddable Watson NLP Emotion Predict service.

Install dependencies with `python3 -m pip install -r requirements.txt`.
Run `python3 server.py` and open the application on port 5000.
Run integration tests with `python3 -m unittest test_emotion_detection.py`.
Run static analysis with `pylint server.py`.

The Watson endpoint is accessible from the Skills Network Theia lab environment.
